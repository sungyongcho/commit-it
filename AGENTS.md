# Commit It maintenance

- Keep this package reusable across repositories and compatible with ordinary SKILL.md loaders.
- User and repository authority stays outside the package. Never publish private account
  routing, host paths, credentials, task records or copied project instructions here.
- Preserve the explicit approval boundaries, actual worker ownership and exact review headings.
- Keep mode-specific detail in references. Change only the requested behavior and direct helpers.
- Verify documentation links and the affected helper behavior with the unittest suite and shell syntax check.
- Do not execute the branch-protection helper against a real repository as a test.
- Publish scoped changes through the maintainer's authorized workflow; never merge or rewrite history implicitly.
